Make a complete menu, not a refusal or instructions. Use a fictional restaurant name when unspecified, two course sections and at least four named dishes with descriptions and individual euro prices. Clear typography, restrained colors, mobile spacing and responsive columns. Inline CSS; no remote images. Keep the first version small and usable. Do not add invented real-world claims. Save and verify using the HTML tools.
